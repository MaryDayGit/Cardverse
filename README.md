# CARDVERSE

Browser-first idle collection game about collecting cards representing video games, anime, characters, creators, studios and franchises.

**Core loop:** Click / Idle Income → Coins → Packs → Cards → Collection → Sets → Idle Income → More Packs

Status: **planning** (documentation v0.2). No PvP. MVP universes: Games + Anime.
