# 23 — MVP Scope

## Must have

### Onboarding
- immediate free first Pack;
- scripted first Pack;
- second Pack opportunity;
- clicker introduction;
- first duplicate;
- Essence;
- first upgrade;
- Sets;
- first passive income.

### Content
- Games;
- Anime;
- normalized content;
- card catalog.

### Economy
- Coins;
- click income;
- idle income;
- Pack costs;
- Essence;
- Pack Tickets.

### Collection
- ownership;
- missing cards;
- quantities;
- favorites;
- Set progress;
- Set completion;
- Set income.

### Progression
- XP;
- level;
- daily quests;
- achievements;
- milestones.

### Persistence
- local save;
- schema version;
- migration.

### UI
- Home/Idle Hub;
- Packs;
- Collection;
- Sets;
- Card Detail;
- Profile.

## Should have

- offline income;
- basic events;
- featured Sets;
- collection showcase.

## Not MVP

- PvP;
- trading;
- chat;
- guilds;
- paid randomized Packs;
- premium currency;
- advertisements as required progression;
- blockchain/NFT;
- native mobile app.

## MVP content target

Start with 100–200 curated cards.

Expand to 500+ before broader testing.

Then build toward 1,000+ approved cards.

## MVP quality bar

- save cannot corrupt;
- click/idle math is deterministic;
- Pack probabilities are tested;
- collection counts are correct;
- duplicate conversion works;
- Set income is correct;
- offline income is capped;
- missing images fail gracefully;
- active content has rights status.
