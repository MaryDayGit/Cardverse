# 09 — Economy

## Resources

### Coins
Primary resource.

Sources:
- click;
- idle;
- Sets;
- quests;
- achievements;
- events.

Sinks:
- Packs;
- click upgrades;
- automation;
- selected services.

### Essence
Collection progression resource.

Sources:
- duplicates;
- achievements;
- events.

Sinks:
- card upgrades;
- crafting;
- mastery.

### Pack Tickets
Reward currency, not purchased for real money.

Sources:
- daily rewards;
- quests;
- achievements;
- milestones;
- events;
- set completion.

## No premium currency in MVP

No premium currency.

No paid Packs.

No ads required for progression.

Optional donations support the project but do not directly buy randomized cards.

## Economy design principle

The economy must have a stable loop:

Click/Idle → Coins → Packs → Cards → Sets → Idle → Coins

Essence is the duplicate sink that prevents repeated cards from feeling worthless.

## Offline earnings

Offline Coins are capped.

Recommended starting cap: 8 hours.

## Anti-inflation

Every major source must have a sink.

Pack prices, click upgrades and Set income must be simulated together.

## Balance targets

Before public test:

- simulate 100k+ pack openings;
- simulate 30 days of player progression;
- measure first Set completion time;
- measure duplicate rates;
- measure average Coins/sec at milestones;
- ensure new Sets take meaningful but reasonable time.
