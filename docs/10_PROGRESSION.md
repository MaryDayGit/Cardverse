# 10 — Progression

## Progression layers

1. Click Power
2. Automation
3. Player Level
4. Collection Milestones
5. Set Completion
6. Set Mastery
7. Seasons/Events

## Player XP

Sources:

- first-time card discovery;
- Set progress;
- Set completion;
- quests;
- achievements;
- upgrades;
- events.

## Player levels

Levels unlock:

- Packs;
- Sets;
- clicker upgrades;
- automation;
- cosmetics;
- event access.

## Daily quests

Examples:

- Earn 500 Coins.
- Open 1 Pack.
- Discover 3 new cards.
- Get 1 Rare+ card.
- Upgrade a card.
- Collect 5 Anime cards.
- Collect 5 Game cards.

Rewards may include Coins, Tickets, Essence or XP.

## Achievements

Categories:

- Collector
- Explorer
- Rare Hunter
- Gamer
- Anime Fan
- Completionist
- Idle Builder
- Event Participant

## Long-term mastery

Mastery combines:

- full unique-card ownership;
- variants;
- upgrades;
- set completion.

Mastery should be a prestige objective, not a mandatory grind.
