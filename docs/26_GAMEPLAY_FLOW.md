# 26 — Gameplay Flow

## Normal session

1. Return to Home.
2. Collect offline Coins.
3. Check daily reward.
4. See active Sets and goals.
5. Click if desired.
6. Claim available quest rewards.
7. Buy/open Packs.
8. Inspect new cards.
9. Convert duplicates.
10. Upgrade cards.
11. Check Set progress.
12. Decide next target.
13. Leave game.

## Long session

Home
→ Idle Hub
→ Pack
→ Collection
→ Card detail
→ Upgrade
→ Set
→ Quest
→ Pack
→ Profile/Showcase

## Return session

Welcome back:

"You earned 8,420 Coins while away."

Then show:

- cards missing from active Set;
- available Packs;
- quests;
- event.

## Decision UI

The game should always expose useful next actions.

Example:

### NEXT GOALS

- Earn 120 Coins → Pack
- Discover 2 cards → Ticket
- Complete 3 more cards in RPG Legends
- Upgrade one card → 50 Essence

This prevents aimless sessions.
