# 18 — Image and License Policy

## Core rule

An API image is not automatically licensed for our intended use.

Every asset must have a rights status.

## Rights states

- unknown
- review_required
- permitted_with_attribution
- permitted_noncommercial
- licensed
- public_domain
- rejected

## Asset metadata

Store:

- provider;
- original URL;
- attribution;
- license information;
- retrieval date;
- rights review;
- local storage status.

## Production rule

Unknown/review_required assets do not enter unrestricted production pools until reviewed.

## Fallback

If an image cannot be used:

- placeholder;
- text card;
- alternate permitted asset;
- remove content from active pool.

## Legal checklist

Before release:

- API terms;
- image licenses;
- data redistribution rights;
- trademarks;
- franchise names;
- commercial status;
- donation/payment rules;
- itch.io rules;
- attribution.

This document is not legal advice.
