# 11 — Seasons and Events

## Purpose

Keep the collection fresh without changing core systems.

## Season

Fields:

- id
- name
- theme
- start_at
- end_at
- sets
- quests
- rewards
- events

## Example seasons

Season 1 — Gaming Origins
Season 2 — Anime Classics
Season 3 — RPG Legends
Season 4 — Anime Villains

## Event types

- featured universe;
- bonus Set income;
- boosted rarity;
- collection challenge;
- discovery challenge;
- limited card;
- limited Set;
- login event.

## Event economy

Events can modify:

- Pack pools;
- Pack Ticket rewards;
- Set production;
- quest rewards;
- discovery XP.

## No paid event advantage

Events are free-to-play.

## Expired content

Already earned cards remain owned.

Expired Sets remain visible in collection history.

## Live configuration

Ordinary event changes should be data/configuration, not frontend code changes.
