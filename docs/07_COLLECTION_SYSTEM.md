# 07 — Collection System

## Hierarchy

Universe → Set → Card.

Examples:

Games → RPG Legends → Elden Ring
Anime → Shonen Legends → Naruto

## Set states

- Locked
- Available
- In progress
- Completed
- Mastered

## Completion

Track:

- unique cards owned;
- total cards;
- percentage;
- rarity completion;
- variant completion;
- mastery.

## Set rewards

Completion may grant:

- Essence;
- Pack Tickets;
- special Packs;
- profile badges;
- cosmetic frames;
- passive income.

## Set production

A fully completed Set becomes an idle income source.

Example:

RPG Legends — 50/50
Completed
+10 Coins/sec

Mastered:
+20 Coins/sec

The exact production curve must be balanced.

## Why Sets produce income

This is the central bridge between collection and idle gameplay.

The player is not simply filling an album. A completed collection becomes an economic asset that funds further collecting.

## Collection Milestones

Example:

10 unique → Pack
25 → Pack
50 → Rare Pack
100 → Epic Pack
250 → Legendary Pack

Milestones are separate from Set completion.

## Set Hunt

Players can select a target Set.

The UI shows:

- current progress;
- missing cards;
- remaining rarities;
- completion reward;
- current production;
- potential production after mastery.

## Missing cards

Filters:

- rarity;
- card type;
- universe;
- set;
- variants.

## Favorites

Favorites appear on:

- profile;
- showcase;
- home.
