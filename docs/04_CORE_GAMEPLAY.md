# 04 — Core Gameplay

## Primary resource flow

### Coins

Coins are the main free economy.

Sources:
- clicking;
- idle income;
- completed Sets;
- quests;
- achievements;
- events;
- milestones.

Sinks:
- Packs;
- clicker upgrades;
- automation upgrades;
- selected collection services.

## Clicker

Base:

+1 Coin/click.

Click Power upgrades increase the amount earned per click.

Costs should grow exponentially or by a controlled curve.

Example:

Level 1: +1
Level 2: +2
Level 3: +5
Level 4: +10
Level 5: +20

The exact curve is subject to economy simulation.

## Idle income

Sources:

- automation upgrades;
- completed Sets;
- collection bonuses;
- rare special cards where appropriate.

Display:

**Coins/sec**

The player should always see:

- current Coins;
- click value;
- passive income;
- next Pack cost.

## Offline income

When the player returns:

"Your collection earned X Coins while you were away."

MVP cap recommendation:

8 hours.

Future progression can increase the cap.

## Pack purchase

Packs are bought only with in-game resources.

No real-money Packs in MVP.

Example:

Discovery Pack = 100 Coins.

Pack costs should scale by pack type, not by arbitrary inflation.

## Pack Tickets

Tickets are non-currency rewards for:

- daily rewards;
- quests;
- achievements;
- set milestones;
- events.

Tickets can open selected Packs without spending Coins.

## Player agency

The player can progress through:

- clicking;
- idle optimization;
- collection completion;
- quests;
- achievements;
- set hunting;
- events.

No single path should be mandatory.
